# Move the native I²C target between the two SCL inputs

Registered after the three D62 captures and before the first swapped capture on 25 November 2026. GPIO19 supplied a clean raw clock on all 18 cases. GPIO27 supplied extra edges on all 18, including when both linked pairs had input pull-ups. The controller's sampled SCL command had the expected 76 or 20 transitions on every case.

With the same FPGA configuration, RP2350B I2C1 peripheral, four enabled pull-ups and 10 MHz acquisition, run six cold loads with native SDA/SCL on GPIO26/27, then six on GPIO18/19, then six back on GPIO26/27. Both pairs support hardware I2C1. Preserve the two SCL inputs in the same sample and keep SDA sampling on GPIO26 for both decoders. Read the four pad-control and function-select registers and PIO2 input-synchronizer bypass setting while the target and capture pins are configured. If they persist on GPIO27 after a successful swap and return control, investigate the physical pin path and its input circuit first. Mixed results or a failed addressed read leave the assignment question unresolved. Validate all returned bytes, address NACKs, command counts and restoration.
