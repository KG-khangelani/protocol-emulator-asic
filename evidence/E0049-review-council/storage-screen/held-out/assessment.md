# What changed when the council programs were held out

Two applications selected independently of the original 15 release images both have 17 distinct full-width instruction words. The 85-word 1-Wire program occupies 340 bytes in the running VM and 126 bytes in the declared byte-packed archive. The 59-word SPI target occupies 236 native bytes and 109 archive bytes. Rounding each complete dense archive to a four-byte boundary gives 128 and 112. Preventing any individual five-bit index from straddling a 32-bit row gives 132 and 112. The dense sequences have 11 and eight straddling indices respectively. Those alternatives keep the same uncompressed numerical instructions and temporal obligations.

The matched PIO power-query program has 32 distinct two-byte instructions, so the same dictionary format expands its 64 resident bytes to 88. If both architectures may choose the smaller of the dictionary or four-byte-header raw representation, the PIO distribution payload is 68 plus the separate four-byte FIFO preload. The VM's is 126 with the command embedded. The resulting 126/72 = 1.75 ratio concerns this transport convention. The actual native resident-plus-preload comparison remains 340/68 = 5.00. The choice of denominator materially changes the magnitude, while neither is an area ratio. [Machine counts for the matched transaction](codec-comparison.json)

The unchanged verified VM loader emitted 712 steps for 1-Wire and 498 for the SPI target. It wrote and read back 340 or 236 program bytes in each direction. A host expanding a downloaded package before using that loader performs exactly this work. Even a new controller-side packet decoder that retained full expanded readback would save only one leg of the byte payload. Clocking an ideal 712- or 498-step plan continuously at 50 MHz would occupy 14.24 or 9.96 µs. External programming, GPIO switching and measured wall time require their own transport and clock model. [Host action inventory](counts.json)

For arbitrary 128-word public readback, 2^4096 distinguishable input bit strings need at least 4096 variable-state bits in any lossless representation, before tags or validation state. The all-distinct control costs 628 bytes under the fixed-width dictionary, or 516 with a four-byte raw header. Supporting current writes, invalidation and exact byte readback is a stronger requirement than fitting the observed corpus. The existing ASIC has a 256×32 physical macro and exposes 128×32 logically. Code compression cannot reduce that installed macro footprint. Reclaiming otherwise unused rows for another role, qualifying a smaller macro, or expanding a limited logical capacity are different design hypotheses. [Qualified production profile](https://github.com/KG-khangelani/protocol-emulator-asic/blob/e90cca228490423a7fe7c4ae40f7e669200b4d0e/docs/specs/g2-production-profile.md)

A direct compressed fetch needs an index and the addressed literal before dispatch. A one-port synchronous store holding both tables ordinarily needs two dependent accesses on a miss. Dense indices spanning a word boundary pose an additional alignment issue. A dictionary in registers, a separate bank, a cache, or host/loader pre-expansion can change this dependency. Each requires its own storage, decoder, wire timing and branch-miss accounting. A one-cycle throughput claim needs measured first-word, arbitrary/data-dependent branch, back-to-back output and timeout/fault cases, plus a real mapped storage choice. A library-compression decision instead needs measured serialized bytes, host RAM/flash/code, expanded readback and wall time on an actual constrained transport. The council's code-density result merits retaining as an encoding observation while these decisions stay distinct.

Reproduce both counts from the repository root with the two commands below. They use the unmodified release assembler and the retained PIO machine-code input.

```powershell
$formatCheck = Get-ChildItem -LiteralPath evidence/E0049-review-council -Recurse -Filter compare_formats.py | Select-Object -First 1
python -I -B (Join-Path $formatCheck.Directory.FullName count.py)
python -I -B $formatCheck.FullName
```
