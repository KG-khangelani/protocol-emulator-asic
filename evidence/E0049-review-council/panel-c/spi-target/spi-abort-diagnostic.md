# Timing and capacity tests following the SPI abort failure

At 15:49 UTC on 24 November 2026, before generating variants, the original 59-word target has completed its trials. Its 1,563 ns release after CS deassertion on a stopped SCK remains a failed 160 ns criterion. Keep the 16:18 cutoff and the original scratch allowance.

**Timeout trade.** On release RTL, change only the two response-loop WAIT_PIN operands that await SCK falling after data sampling. Sweep integer timeouts 0 through 80, including the original. Keep the earlier reception, rising-edge waits, status markers, timeout cleanup and both replies identical. For each operand, require an 0xA5 positive transaction with a 1,000 ns half clock and all four baseline phases (1, 7, 13 and 19 ns) and separately test the original active-MISO abort at 250 ns half-clock, 7 ns phase. A timeout that stops driving before CS rises cannot qualify as a fast abort. Require the operand to meet both the old normal setup/hold/release and 160 ns abort bounds. Retain the complete row matrix, boundary values and the first failure reason. If an operand meets both partial tests, run the full frozen original opcode/rate/phase/error suite before crediting a repair. Fixed shorter timeout alone is a tested family, and other firmware remains possible.

**Bounded cooperative polling.** Try to assemble one conservative alternative that uses only the original target pins, initial opcode check and two literal reply bytes. A poll loop checks CS and the requested clock transition each pass, jumping to a released error state on CS deassertion. Its bounded count covers at least the original 1 µs slow half-clock and terminates on missing SCK within 2 µs. Direct replies avoid losing partial SHIFT state when an absolute branch exits a poll loop. Omit redundant SETs on consecutive equal data bits. Preserve the original timing, phase, invalid-opcode and missing-clock cases; add a missing clock during a driven reply and early CS in both clock phases if the source fits. If over 128 words, retain the assembler's exact failure and count the actual instruction words per section; the size of this construction is evidence about this construction only. Estimate timing still requires actual public-port execution before promotion.

**External option.** A default-open bilateral switch could disconnect the bus from MISO at raw CS deassertion while preserving command-phase high impedance; another design could supply a separate response-valid OE signal. Its costs include part/pin/control, propagation and loading, power-up state, independent load isolation, frame authorization and handling a second CS assertion before rearm. Neither option is part of the layout or the current model.
