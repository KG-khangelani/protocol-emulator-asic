# What would a new deliverable add?

The archived kits already take a reader from assembly source to a reproducible binary, decoded metadata, timing listing and clocked load plan. From the unpacked G4 submission bundle a reader can run the first command below. From the unpacked G5 starter the second builds the control waveform and the third runs its independent checker tests. Each assembly command needs a fresh output directory. Python 3.11+ and its standard library suffice. [G4 release and assets](https://github.com/KG-khangelani/protocol-emulator-asic/releases/tag/v0.1.0), [G5 starter and assets](https://github.com/KG-khangelani/protocol-emulator-asic/releases/tag/v0.1.1)

```text
python tools/assembler.py programs/od128-sram-v1/uart_tx.asm --out build/my-uart
python tools/assembler.py experiments/waveform_replay/control.asm --out build/my-control
python -m unittest discover -s test -p test_waveform_replay_oracle.py
```

At 16:06–16:08 UTC an isolated, network-disabled Linux process ran the assembler with Python site packages disabled. The output files for G4 UART and G5 control each matched all four published digests. The first run used a new output directory named `build/first`. The second used the literal README destinations and obtained identical bytes. G4 used version-bound Git blobs individually matched to the public bundle's complete member manifest and original archived compiled outputs. The full G4 submission ZIP was unavailable locally. G5 inputs came from the retained public starter ZIP. Both G4 and G5 had only an output-directory option beyond the source argument and help. The proposed `--profile selected-power` spelling returned exit 2 in both with no output. G4 UART emitted 76 steps (39 with enable low); G5 control emitted 176 (87 with enable low). Both ended with two enable-low flushes at UI `00`. Earlier isolated G5 tests exercised the two sources, all eight original outputs, the twelve checker tests and the invalid-source control. These experiments measured machine behavior. [G4 source and physical handoff](https://github.com/KG-khangelani/protocol-emulator-asic/blob/5bdc0e6b6449a829a5da1f8f9a8060257e974843/docs/submission.md), [archived G5 waveforms and limits](https://github.com/KG-khangelani/protocol-emulator-asic/blob/022834146efcb5f388a4d6ec23b3b705a0df7ef8/docs/waveform-replay.md)

To repeat this check on Windows, run the following in a full H: checkout with the tagged Git objects, retained original archives and cached workbench image. Place `offline_entries.py` in `$panel` or set that variable to its retained location. The probe writes only under the fresh output mount. Its manifest records each digest, default enable/selector, exit code and UTC span.

```powershell
$repo = (Get-Location).Path
$panel = Join-Path $repo 'evidence/E0049-review-council/panel-c'
$out = (New-Item -ItemType Directory -Path (Join-Path $repo 'build/council-offline-entry-replay-01')).FullName

docker run --rm --pull=never --network none --read-only --mount "type=bind,source=$repo,target=/repo,readonly" --mount "type=bind,source=$panel,target=/probe,readonly" --mount "type=bind,source=$out,target=/out" -e TMPDIR=/out $image python3 -I -B /probe/offline_entries.py --repo /repo --out /out/replay
```

## Conditional priority after nominal mapping

Removing UART burst operations reduced nominal mapped cell area from 44,717.8158 to 42,587.7858 μm². Both models have 353 sequential cells and the same 49,488.4992 μm² memory. Including that memory gives 94,206.315 to 92,076.285 μm², a saving of 2,130.030 μm² or 2.261027%. Released eight-word TX and RX then fault, although loading and byte verification still succeed. Manual substitutes use 17/18 words and 152/160 cold steps compared with the originals' eight words and 76 steps. Mapping establishes a measured resource trade. Routing, achieved physical timing, die/tile class, power and physical acceptance of the ablation still require evidence. A replacement claiming the old interface ID would expose a concrete software compatibility failure.

1. Keep the released physical candidate and the owner's deadline work first. In parallel use the already-shipped G6 materials for the supported owner record and the two short archive-start usability tasks. Investigate only observed documentation failures. Spend the first software implementation hours on the missing selected-power interpreter and controller ownership contract.
2. If a named fixture, isolation and instruments are already accessible, a calibrated cold transaction answering a real operator question comes before another architecture pilot. Without the fixture, complete the digital product path and favor a bounded equal-role comparator. The 59-word unchanged-core SPI target rejects 254 unknown opcodes, yet its active MISO release after one stopped-clock abort takes 1,563 ns against a 160 ns requirement. In Panel B's retained switch test, simple CS gating hid the drive while deselected, then exposed stale state on immediate reselection, and the second valid A4 did not return 3C. A matched PIO *target* should run the same frame, abort and immediate reselection matrix. The newly verified 30/32-word, eight-mode PIO SPI *host* is a different endpoint.
3. The 2.261% estimate lowers production priority for burst removal while giving the research question a concrete comparator. Promote a bounded paired place-and-route or energy test only when a named tile, congestion margin, power target or binding architectural decision could change on this scale. Retain compatibility through a distinct target/capability and fully requalify any physical candidate before replacement. A traceable 2,130 μm² saving that enables a required function, meets a physical budget, or changes tile class would reverse the current ranking. An engineering-hour estimate or unanimous panel vote cannot establish that condition.

The contest and release handoff remain separate from these experiments. Submission and result notices require current organizer evidence and the owner's authorized action. The deliberately small human trial, conditional fixture access and the switched-SPI model's idealized electrical behavior limit this priority order.
