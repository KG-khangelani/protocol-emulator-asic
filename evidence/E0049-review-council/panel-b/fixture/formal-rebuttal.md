# Rebuttal to the engineering ranking, 24 November 2026

**Change the order when the application requires two SPI targets or receiver behavior at the end of a wire.** All 1,160 tied-high G4 I²C records matched and panel A/C accounted for the G5 board-applicable schedules. More copies of the same digital transcripts have little leverage over an unknown fixture. If an equipped partner can provide a named target, independent clock, safe isolation and calibrated analog capture now, I would spend that bench window on endpoint/ownership evidence before writing broader board-use guidance. The existing owner G6 session can proceed in parallel. If the only available task is software, implement the restricted cold profile and schedule G6. No final 2027 chip, FPGA fixture or instrument availability was demonstrated in this council.

**A named requester that requires release within 160 ns and a second transaction without host reload changes which architecture deserves work.** The 59-word candidate handled complete frames but held MISO for 1,563 ns when CS rose and SCK stalled, 1,403 ns beyond that synthetic contract. Its separate timeout sweep found 48–80 ticks for the declared slow-clock cases and 2–9 ticks for the fast abort, with no overlap. This supports an isolated experiment on a CS-aware peripheral, a short fixed target state machine or a dispatch mechanism that can cancel a pending wait and rearm a frame. Require the same A4/A5 replies, 60/40 ns response setup/hold, clean command-phase release, bounded deselection independent of SCK and a second command without loader assistance. Charge additional pins, states, state machines, external gates and host service. These results reject one firmware recipe under a stated stronger contract. They do not establish an ISA lower bound. A real target’s published 3.3 V disable bound supplies context for the physical scale, but does not impose a 160 ns requirement on the competition. [Microchip 25LC256, Table 1-2, parameter 15](https://ww1.microchip.com/downloads/aemDocuments/documents/MPD/ProductDocuments/DataSheets/25AA256-25LC256-256K-SPI-Bus-Serial-EEPROM-20001822H.pdf#page=3)

**Fresh test of the proposed external CS gate.** The 498 original clocked loader steps loaded the same 59-word image in RTL and the actual G4 functional netlist. All 20 cases in each representation matched at every sampled endpoint. Direct wiring, a CS-only one-way buffer, a bilateral switch and a switch inhibited after abort each returned the original A5 → A7 in an uninterrupted frame. The one-way buffer actively drove during all eight command bits from a released, weak-low ASIC pad. Its normal reply still passed a byte-only check. A public Tiny Tapeout pad does not separately expose its chip-side OE to that buffer. [Frozen question](fixture-contract.md) · [Full test results](results/switch-reselect.json)

The bilateral switch isolated the bus with CS high. It reconnected a stale high output when CS fell 160 ns after the abort. The opposed simulated peer resolved to X and the equal-valued peer resolved to one. The stopped-high version demonstrated electrical ownership on a repeated selector level. A second schedule restored SCK low 80 ns after deselection, asserted new CS at 160 ns, waited 300 ns and supplied a complete mode-0 A4 command. Direct, bilateral and inhibited branches returned **eight released bits** instead of 3C. The one-way buffer returned eight actively driven zeros. The deliberately enabled peer was a current-sensing substitute at reselection and released before the second command clock. Nothing in this test measured current or hardware delay. [Public-pin testbench](switch_reselect_tb.sv) · [Case rows](results/switch-reselect.json)

A default-open bilateral switch can satisfy a *fixture’s* requirement to disconnect the branch while CS is high. It preserves a genuine command-phase high impedance. An active tri-state buffer needs a separately qualified response-enable signal as well as CS. Either approach needs independent disconnection of **all** shared target signals during loader read/write, a defined power-up state, and a way to prevent stale execution from accepting a new frame. The fixture owner pays for its switch or additional pin, enable logic, routing capacitance, timing, wake-up and rearm policy. An enforced wait-for-ready or explicit host reload restricts requester scheduling and must enter the advertised transaction model. An instrumented disconnection alone cannot establish native abort or repeated target service. A source example switch has a 6.5 ns maximum control-to-disable value at 3.3 V in the specified DBV/DCK conditions. Package, external enable timing and bus loading remain part of the system result. [TI SN74LVC1G66 Rev. R, §5.6](https://www.ti.com/lit/ds/symlink/sn74lvc1g66.pdf#page=7) · [TI SN74LVC1G125 Rev. U, §7](https://www.ti.com/lit/ds/symlink/sn74lvc1g125.pdf)

Panel C accepted the distinction between CS-high disconnection and an independently served next frame. Panel A also agreed that its original one-wire state machine and PIO host measurements do not qualify a target abort. My remaining dissent concerns scheduling. A time-limited, equipped measurement or a documented need for autonomous, closely spaced target frames can outrank another demonstration guide. A synthetic deadline by itself does not justify changing the frozen production RTL. The immediate screen and decision thresholds are in the [fixture procedure](bench.md).
