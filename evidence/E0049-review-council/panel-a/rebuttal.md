# Replies to the 1-Wire electrical and operating-cost objections

The electrical seat identified a difference between a commanded release and the time when a DS18B20 recognizes a high level. Its data sheet starts the 15–60 µs presence delay at the **detected rising edge**. The three simulations start it at the controller's ideal release. For a hypothetical 3.3 V pull-up, 4.7 kΩ and 1 nF, an ideal first-order rise to the parasite-powered input's guaranteed 3.0 V high takes `−RC ln(1−3/3.3) = 11.27 µs`. A write-one release at 6 µs then leaves only 9 µs before the earliest possible 15 µs write sample. A device responding 60 µs after detecting high could also begin its presence pulse at about 71.27 µs from controller release, after the nominal 70 µs decision. This calculation concerns a declared electrical example and a guaranteed input level; it gives neither a measured switching threshold nor a statistical probability of failure. Identical aligned digital output edges across all three implementations can carry the same physical defect. A bench would vary VPU, load, local/parasite supply, realized rise time, target write-sampling phase and read-response start. A scope and independent decoder could compare the actual target-end DQ threshold crossings at reset, 6 µs release and read sample. The industrial seat requested cold and steady costs. Cold start on the matched PIO comparison consumed 115 register operations before a single enable write. A single 32-bit FIFO write held all 16 command bits. No MMIO operation followed launch during the exchange. The checked groups and first complete command transcript are in the PIO records. The 712 VM steps are reciprocal eight-bit project-port transactions expressed as sampled chip edges. The fixed implementation took three initialization edges before its start transition. Stable late observation of the **latest** operation result is available on all three for a terminal host under the corresponding hold assumptions. Reusing the same device for a second operation requires a safe clear, explicit transaction identity or acknowledgement and a rearm that keeps external drivers from contending. The PIO comparison's 500 additional clocks verify only post-terminal stability, and its decoder spins in a self-jump, with no direct low-power conclusion.

One proposed PIO steady path uses one disable/restart register write, two forced SETs to release and clear markers, one forced JMP to zero, one FIFO write, one forced PULL and a final enable. This counts six prior MMIO operations plus launch on the assumptions that the previous command was consumed, the resident program and configuration remain trusted, and the peer is idle. The cold experiment did not run two consecutive queries. An added full image readback or FIFO-state check changes the count. The existing I²C rearm result belongs to its own protocol and host profile. For both PIO and VM request a paired cold/steady run on the same public pins with two successive differing responses and an intervening absent-target case. Require no stale result or fresh program write on the declared steady path, correct ownership and explicit invalidation on power loss. Only then measure elapsed time per interface, include bus-clock and transport configuration, and separately record first-time setup and per-query service. A user edit-to-verified-run comparison would also need a frozen edit, common result criteria, independently recruited operators or a counterbalanced order, exact assistance and actual elapsed times.

## UART instruction ablation

The chair's completed firmware test answers the timing and stop-bit objections for the frozen matrix. Each released/manual pair exercised 272 TX cases and 278 RX cases across P4 and P434, bad first and second stops and a no-start case. Six mutated direction, edge or TX-slot controls were caught. The manual TX program uses 17 words versus eight, with 152 versus 76 loading edges. Manual RX uses 18 versus eight and 160 versus 76 edges. Normal RX terminal status changes from A7 to B1. The two stop errors change from E6 to E8/F0, while no-start remains E1. The old HostReader rejected otherwise successful manual runs, and both bad-stop paths discarded tentative bytes. This is direct evidence that manual shifting can meet the declared data/pin timing when the host binds the new program. It also establishes a real compatibility and program-size cost. A future hardware-removal study must preserve the observation contract it claims, account for the absolute jump/loop and error behavior of malformed programs, and measure the marginal change in fixed cell/macro/routing resources. Its outcome could be zero after shared resources and the unchanged memory tile are counted.
