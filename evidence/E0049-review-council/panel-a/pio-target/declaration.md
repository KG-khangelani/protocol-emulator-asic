# One-bit target abort and reselect property

At 16:13 UTC freeze a partial target property with an external requester, one RP2040 PIO SM, ordinary 50 MHz synchronization, retained Wokwi decoder and official pioasm. SCK0, MOSI1 and active-low CS2 are inputs and MISO3 is the device's only output. An idle target starts released. The first rising SCK edge of each selected frame captures one request bit. The target echoes that bit on MISO for the next rising edge, holds it through the response high interval and releases MISO within 160 ns of the following normal falling edge. A requester can instead assert CS high while MISO drives and SCK is stopped low; MISO must release within 160 ns of detected external CS rise, remain released through reselection, and serve a subsequent opposite bit without host activity. Command/response bits are chosen so a stale reply is observable. This directly exercises one ownership and restart property. The two full 8-bit commands, unsupported-opcode rejection, external watchdog, all abort positions, complete original status/host protocol and normal eight-bit duration are outside this experiment.

Use 0.5, 1 and 2 MHz with requester phases 1, 7, 13 and 19 ns against the 20 ns system clock. At each rate/phase run two normal transactions (request 1 then 0), a stopped-low abort followed by reselect exactly 160 ns after deassertion, and a selected slow/pause control that leaves SCK low for at least 2 µs while MISO drives. Vary abort position by 0, 20 and 40 ns relative to a base safely inside active drive, covering the main polling-loop residues across the phase matrix. The reselected request receives at least 300 ns CS setup before its first SCK rising. Require no illegal drive of requester pins, MISO high impedance through request sampling, requested reply bit with at least 60 ns setup and 40 ns hold on complete replies, no early release in the selected pause, timely OE release at CS abort and normal last falling edge, and successful immediate opposite-bit frame. Track actual signal ns times. A model exposing delayed pad registers is still a digital observation.

Three program controls are permitted, each compiled separately. Mask all active CS tests and require the aborted case to fail. Replace the returned bit with a constant one and require the second response to expose the stale-looking value. Change the active clock-rise loop to clear its output while SCK is still low and require the slow control to fail. If first implementation fails, retain its images, measurements and error before attempting one limited correction. Enforce one SM, ≤32 instruction words, no FIFO or CPU help from first launch through final reply, no auxiliary pins, no synchronizer bypass and explicit cold program verification. End at 16:30 UTC or earlier on a bounded result. Additional scratch budget 400 KiB.
