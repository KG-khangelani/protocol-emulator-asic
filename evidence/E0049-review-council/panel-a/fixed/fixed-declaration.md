Recorded before implementing or executing the candidate. Compare against the chair's `evidence/E0049-review-council/onewire/contract.md`, program, fixture and oracle as they exist on 24 November 2026. The fixed candidate will implement the same single-target power query, initial-line and recovery checks, ideal wired-AND port, terminal markers, 50 MHz clock, low pulse widths and slot spacing. Keep the unmodified external target and checker from `power_query_tb.sv` and `screen.py`. Reuse makes the **operation contract** directly comparable. It does not create an independent second oracle.

The independent variable is a dedicated controller with a phase timer, bit index, constant Skip ROM/Read Power Supply command, two-flop input synchronizer and terminal result. Its public bootstrap will use `ena=1`, one reset edge and two inhibit edges to initialize its input. Start by lowering a dedicated public input bit before the next edge. Count these three preparation edges, the launch transition, any runtime host operations, fixed command bits and the width/purpose of retained state. The chair's resident image consumes 85 × 32 bits (340 bytes) and its published loader takes 712 edges. The fixed design has no loader or post-fabrication program memory. Its silicon embeds the procedure. Do not compare these interface costs as if they purchased the same capability.
