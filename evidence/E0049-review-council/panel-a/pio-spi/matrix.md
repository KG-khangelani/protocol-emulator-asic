# Frozen case matrix

For each of the eight mode/order combinations, exercise the exact candidate with nine edge-only RX bytes (`69` hex and eight single-bit masks), pairing `69` with TX `96` and each walking one with its TX complement. Add exact and late programs with early, late, and mixed held responses for RX `69`/TX `96`. The constant response offsets are 1 and 96 quarter-clocks after launch, and the mixed vector is `1,96,16,80,24,72,32,64`. Run three controls per mode/order: the late program against edge-only MISO, a one-clock-early program against edge-only MISO, and incorrect SCK polarity under a held response. Inventory: 120 intended positive cases and 24 intended rejections. The shifted-capture controls should report the complemented return byte; the polarity control must report actual pin disagreement even if the data bytes look correct.

Monitor RX FIFO not-empty and the PIO IRQ flag non-destructively as test instrumentation. The consuming host waits until operation closure, then performs its single RX FIFO pop. The resulting held-byte projection can be scored against the VM oracle only with that observation boundary labeled. The PIO port cannot supply the VM's persistent nondestructive byte register or the VM's HALT/PC encoding. Stop the transaction verdict at the original HALT edge and check a further 400 clocks of stable wire/IRQ/FIFO state before popping the byte.
