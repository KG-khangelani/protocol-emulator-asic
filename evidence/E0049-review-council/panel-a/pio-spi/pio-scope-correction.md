# Corrections to the earlier PIO comparison

The 1-Wire challenge called each host access “APB-style.” The measured record contains 115 32-bit MMIO operations before launch. Of these, 107 access PIO0 on the fast AHB-Lite peripheral port and eight access the APB-mapped GPIO/pad configuration blocks. Launch is a further PIO0 write. These bus distinctions reinforce the requirement to measure the actual host implementation. The transaction count and all observed words are unchanged. [RP2040 datasheet §§2.1–2.2, bus fabric and address map](https://datasheets.raspberrypi.com/rp2040/rp2040-datasheet.pdf#page=16)

The 1-Wire Wokwi harness used a 1 µs issue clock, instantaneous decoder outputs and two 20 ns input-synchronizer stages. It tested a declared model of the PIO program. RP2040 §3.5.6.1 also documents an output-mapping register and an input-mapping register, for four system clocks in a synchronized, zero-propagation loopback. The extra two stages matter for single-clock SPI return pulses. The original 1-Wire observation record preserves the initial abstraction. At its discrete healthy fixtures the shortest ideal presence interval covering the 70 µs sample is 15–75 µs and the latest possible start is 60 µs. The modeled parasite zero spans 10–45 µs around a 14 µs read sample. Adjusting an edge by one or two 20 ns system clocks in those particular interior windows cannot change the declared sampled bit; there is no resulting guarantee about marginal phases or remote bus thresholds. [RP2040 pin-mapping and input synchronizer stages](https://datasheets.raspberrypi.com/rp2040/rp2040-datasheet.pdf#page=331)

The chair's later asymmetric-digital-threshold experiment identified a separate physical boundary. With specified 1 nF, 4.7 kΩ, 3.3 V and 3.0 V remote high threshold, an 8 µs high interval after a write-zero is shorter than the modeled 11.28 µs rise. The receiver may see no falling edge on a subsequent slot even if the controller emits every expected edge and reaches a plausible terminal result. This observation concerned the declared threshold model. A named actual bus, voltages, loads and independently observed remote thresholds are needed to determine the supported operating envelope.
