# Does UART need the timed byte instruction at 128 words?

Pre-execution screen proposed in panel A's independent brief. Replace each UART `SHIFT_BURST` with eight `SHIFT_STEP` operations at the same bit spacing on the unchanged production RTL. Count program and host costs. This tests whether firmware can omit the instruction in two specified workloads. Removing hardware and measuring area would require a separate candidate.

Unroll the two frames, select TX0 and TX1 explicitly, and use one counted loop per byte. Pay for the loop dispatch out of the preceding wait. Keep the public output edges, output direction, raw-capture values and timing, stop checks, and semantic HALT/FAULT timing. The original image's public PC changes when code moves. Record terminal signatures and test the released RX host's actual acceptance rule.

Use the frozen two-frame 8N1 wire mathematics at P434 and the reduced P4 corner. Compare the released programs and candidates against independent frame bits, capture edges and terminal outcomes. Test all 256 first-byte/complement pairs at P4, distribute the four quarter-clock start phases across those pairs. At P434 cross `00/FF`, `55/AA`, `96/69` and `FF/00` with all four phases. Test first and second bad stop on RX at both periods. Drive public loader writes/readbacks, program both payloads, and release the shared input before running. FPGA and pad timing, baud error and unbounded streams are outside the fixture.

Require zero unexplained wire/raw/terminal mismatches. A wrong second TX slot must be detected on distinct payloads. A one-clock wrong wait before the first manual data bit must be detected on timing or raw-capture checks. The old host's `A7` terminal rule must be challenged on the new RX program; success on the wire does not by itself preserve software compatibility. Retain failures. Budget one Icarus run series, under 8 MiB of H: scratch and a 16:20 UTC cutoff.
