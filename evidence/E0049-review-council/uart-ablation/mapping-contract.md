# How much mapped logic is associated with the timed byte operation?

The [firmware ablation](README.md) measures an instruction's software value but leaves its gates in place. Before ranking an ISA-removal proposal, perform a small, separately named hardware screen on **copies under H: build/**. The qualified sources, configurations, interface and stable releases remain the reference. Neither experimental copy is a production profile.

Use a copy of the production top, store, synchronizer and engine for both runs. For the candidate change only the 16-bit decoded burst period from the instruction field to zero. Legal burst encodings then fail the minimum-period check, while bit 21 still distinguishes reserved burst encodings from ordinary manual shifts. The phase-sample form can still use the period register's private value of one. Keep the actual single-port SRAM black box and full top-level ports in both mappings. Identify both entire source sets and the one input-line difference.

Run matched flattening, generic synthesis, DFF and ABC cell mapping with the same pinned physical tool image, nominal standard-cell and actual SRAM Liberty files. Check every mapped cell's area, exactly one original macro per design, no unmapped logic, actual sequential-cell count and separate standard-cell and total cell-plus-macro area. An engine-only count, ABC timeout or differing flow is insufficient for this claim. This is a fresh exploratory map, with no claim of equivalence to the G4 LibreLane recipe, utilization, layout, routed timing, power or silicon.

For the candidate, run the manual UART TX/RX pin checker over its existing 550 cases with the dated frame oracles, first/second bad stop and missing start. Require the original two burst examples to fail their expected wire/terminal behavior and record the observation. Exercise the existing public G3 loader, SPI and I²C groups on the candidate and compare their original recorded outcomes. Record a failure or unmet gate. Whole-chip formal equivalence, full stressed I²C, SRAM timing and actual layout must be qualified before any adoption. Deleting an instruction changes compatibility even if the mapped area falls.

The question is whether a detectable mapped area saving survives the fixed macro. Report the percentage and both denominators regardless of its sign. Budget two nominal maps with 180-second ceilings, one public simulator for candidate behavior, less than 16 MiB of reusable scratch for this study, and a 16:25 UTC cutoff. Register this test before editing the candidate or running Yosys.
