This research prerelease adds the formal proof for the existing eight-word
SPI mode0/2 programs under their documented input-hold requirement.

### New qualification

- Actual public-loaded programs pass k-induction with symbolic TX/RX bytes,
  both bit orders and both clock polarities.
- Twelve finite harness preflights pass independent image and pin checks.
- Deliberately wrong MOSI expectations and removal of the first bit's hold
  requirement produce validated reachable counterexamples.
- CI and release publishing now require this proof and both controls.

The input must hold through the documented interval: the delayed instruction
consumes raw input22 core ticks after the wire sample. A correct value only at
the sample edge is insufficient.

[E0028](https://github.com/KG-khangelani/protocol-emulator-asic/tree/v0.1.0-alpha.2/evidence/E0028-held-program-induction)
retains the proof, witnesses, source hashes and initial harness failure.
Production and experimental candidate RTL are unchanged. Modes1/3, full
four-mode SPI, arbitrary firmware/pauses, new physical fit/timing, Fmax and
silicon remain unqualified. Owner fluency remains pending.

The attached manifest identifies the exact source, tested container digest
and publication run. The SPI proof result is attached as `spi-held-proof.json`.
