This research prerelease adopts one programmable SRAM core for UART, SPI and I2C
after combined functional verification and fresh 8x4 CMOS5L physical qualification.

- The same public-pin loader and temporal engine run UART transmit, bounded
  UART receive, all four SPI modes in both bit orders, and Standard-mode 100 kHz
  I2C controller programs. There is no dedicated protocol-specific RTL path.
- The core exposes 128 logical 32-bit program words in one 256-by-32 SRAM macro,
  alongside 353 register bits. Interface **0x22** makes program-byte readback
  clocked; the documented instruction and pin timing contracts are preserved.
- All thirty current RTL groups pass in both simulators. Source-matched engine,
  reset, prefetch and real-memory properties pass with checked fault controls;
  the independent historical formal baseline remains separate. Whole-chip proof
  timeouts remain recorded as inconclusive.
- Official run 43348171110 passes the complete manufacturing flow, all ten
  prechecks and all eighteen public netlist groups. The submitted netlist is
  byte-identical to the corrected netlist tested by both local simulators.
  The 1,052 SPI, 1,160 I2C, four boundary and 36 abort reference records agree.
- At the unchanged 20 ns target, worst reported setup/hold slack is
  **+5.595886/+0.120791 ns**. Required physical, electrical and power checks pass.
  The routed standard-cell area is 61,294.1 square micrometres; the macro is
  separately 49,488.4992 square micrometres. The die allocation remains 8x4.
- The complete mapped footprint including SRAM is 78.5306% below D39 under
  matched conditions. D39 failed routing, so this is a mapped comparison only.

[D48](https://github.com/KG-khangelani/protocol-emulator-asic/blob/v0.1.0-alpha.6/docs/decisions/0048-adopt-qualified-sram-production.md)
and [E0045](https://github.com/KG-khangelani/protocol-emulator-asic/tree/v0.1.0-alpha.6/evidence/E0045-g2-sram-qualification)
bind the adoption, original archives and replayable audits. Physical artifacts
were produced at `94a30825c633778b8fb1b8374b79d1a419d3fc96`; all twenty
qualified physical input files are copied byte for byte into production.
Clean default-command CI uses the actual `src/` directory and retains its
producing source, eight stages and immutable container identity. The separate
release manifest identifies the publication commit and exact tools image.

The G2 package contains six unchanged physical ZIPs, the original default-command
CI ZIP, the complete E0032-E0045 research trail and its frozen replay inputs,
decisions, a production/source manifest and a separate checksum list. The earlier
congestion, power, rule-check, pin-span and timeout failures remain available.
The historical generic timed-GPIO release comparison still selects P in its
limited scope; D35's physical rejection of P and compact10 qualification remain
unchanged, as do M0's original 6x4 results.

D43-D47's explicit power construction, nine input buffers, public-pin guard,
two-file Magic contact-rule alignment and selection of existing full-height
supply ports remain part of the qualified flow. All original acceptance stages
and checks remain. The fast model set combines -40 C standard cells with -55 C
SRAM and is not an isothermal characterization.

UART retains framing/phase/error, bounded host-service and delivery limits;
continuous autonomous reception is unqualified. SPI requires its declared input
hold and preserves the expected edge-only failures. I2C assumes the declared
resolved digital bus and external pull-ups; it covers 7-bit addressing,
write/read, repeated START, ACK/NACK, stretching, final-edge priority and bounded
cleanup. This is not analog-bus compliance, broad device interoperability,
fabricated hardware, measured maximum frequency or owner fluency.

G3's usable assembler/program toolchain and the final submission package remain
separately ordered work.
