The intended release packages the unchanged G2-qualified shared protocol core
with G3's readable assembler and a current submission write-up. Interface
`0x22` provides 128 logical 32-bit program words in one 8,192-bit SRAM macro,
alongside 353 register bits. Thirteen programs demonstrate UART transmit and
bounded receive, both bit orders of all four SPI modes, and I2C write, read
and repeated-START transactions on the same engine.

The 20 ns clock setting is a physical-flow target, not measured Fmax. Netlist
tests are functional zero-delay simulation. The fast model set combines -40 C
standard cells and -55 C SRAM. UART RX retains framing and bounded host-service
limits; SPI requires the declared input hold; I2C retains external pull-ups and
digital resolved-bus assumptions. No analog-bus, fabricated-silicon, FPGA,
continuous autonomous RX, unrestricted interoperability or owner-fluency result
is claimed. Submission readiness does not mean a competition entry was sent.
