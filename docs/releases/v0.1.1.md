# G5: triggered digital waveform replay

Two 20-word programs reuse the unchanged G4-qualified chip as a triggered
source of irregular digital stimulus. The timing-fault program moves one
selected rising edge by two clocks, while every later output transition and
the final release retain their original timing. At the assumed 50 MHz clock
the shift is 40 ns; this is a digital schedule conversion, not a new frequency
or physical pad measurement.

[Qualified source 66743b6](https://github.com/KG-khangelani/protocol-emulator-asic/tree/66743b60b93508d2f00f23fa2cc2ac7db244bc3a)
passes [run 43697229433](https://github.com/KG-khangelani/protocol-emulator-asic/actions/runs/43697229433):

- 21 public-pin cases in each of Icarus and Verilator, including five expected
  rejections; a separate clean clone reproduces every record and trace byte.
- All 366 producing inputs match the committed source. Both programs occupy
  80 bytes; only WAIT words 9 and 11 differ.
- Trigger phase/boundary, timeout cleanup, pin ownership, disabled-clock
  stretching, actual corrupted load-byte rejection and reload recovery pass.
- The existing thirteen UART/SPI/I2C examples retain their bytes and pass all
  55 public cases per simulator, including fifteen expected rejections.
- Retained evidence replay passes, and five deliberately rehashed bad-evidence
  controls are rejected. Native Windows and Linux produce identical compiled
  program artifacts.

Start with the [example guide](https://github.com/KG-khangelani/protocol-emulator-asic/blob/main/docs/waveform-replay.md).
The software bundle supplies the standalone assembler, both readable sources,
eight compiled artifacts and independent checker tests. The original CI ZIP
preserves the actual qualification and clean reproduction. Their manifest and
`g5-SHA256SUMS` bind the downloadable bytes. Publication verification is
recorded separately in E0048 after downloads are checked.

All twenty physical inputs remain identical to
[stable v0.1.0](https://github.com/KG-khangelani/protocol-emulator-asic/releases/tag/v0.1.0).
Its physical reports, layout archives and submission packet remain the hardware
reference. This release adds a software example; it does not claim new physical
qualification, fabricated silicon, an analog glitch generator, unrestricted
asynchronous capture, a new architecture or completed owner teach-back.

The initial unsupported comment syntax and unavailable local Docker engine
are retained in E0048. Correcting only the comments left every instruction,
expected trace and investigation limit unchanged. No competition entry has
been submitted.
