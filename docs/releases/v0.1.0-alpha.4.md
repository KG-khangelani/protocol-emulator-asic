This research prerelease makes the explicit-idle SPI mode1/3 transfer fit
the existing eight-word store through isolated timed GPIO instructions.

- Selected P uses 3,146 generic complete-chip cells and 412 state bits, saving
  443 cells (12.34%) and 65 bits (13.63%) versus the matched ten-word design.
- It adds only 39 cells and no state bits relative to compact8 by reusing the
  existing wait counter for SET and DRIVE post-delays.
- Both simulators agree on 1,052 public transfers per candidate/reference run:
  1,048 positives and four expected input-hold counterexamples.
- P passes general instruction rules, scoped compact refinement and actual
  public-loaded mode1/3 program induction with symbolic bytes/order/polarity.
- Clean CI qualifies both alternatives and selects P on cost. Local refinement timeouts and
  intentional formerly-invalid-encoding compatibility changes are retained.
- Release publishing reruns the full timed comparison and all earlier SPI gates.

[E0030](https://github.com/KG-khangelani/protocol-emulator-asic/tree/v0.1.0-alpha.4/evidence/E0030-timed-gpio-comparison)
retains exact source identities, counts, traces and bounded proof attempts.
Production RTL and the historical compact engine remain unchanged.
Generic synthesis is not CMOS5L area/timing, Fmax, silicon or owner fluency.

spi-timed-gpio.json and its seven supporting gate assets record this publication
run. publication.json identifies the exact source and public workbench digest.
