# UART-TX-8N1 candidate progress report

Date: 2026-10-05. Scope: simulation-first M2-T01 engineering.

## Outcome

The reloadable candidate now emits two distinct back-to-back UART 8N1 frames
without a UART-specific RTL state machine. An eight-word public program uses
ordinary SET, WAIT and LOOP instructions around a reusable timed SHIFT_BURST.
At the declared 50 MHz experiment point, period 434 corresponds to roughly
115.2 kbaud. The first start edge is accepted edge 3, the first stop edge is
3909, the second start edge is 4343, the second stop edge is 8249, and HALT is
edge 8683. Every cell boundary matches the frozen frame oracle.

D16 records the general extension. It reuses the shift datapath and wait
counter, latches a legal period from 2 through 65535, holds the final data bit
for a complete period, and alternates between two public TX payload bytes. The
manual K-SHIFT-8 behavior and its slot-zero payload contract remain unchanged.
No UART start/stop/framing state exists in RTL; those cells remain firmware.

## Verification and measurement

The local locked workbench passes:

- static consistency plus 18 semantic-model tests;
- 14 Icarus and 14 Verilator cocotb cases;
- the GL-shaped harness smoke and waveform-provenance check;
- Verible lint;
- engine proof, all covers, the expected-failing wrong-WAIT mutant, and all
  program/data-store/input-synchronizer proofs and covers;
- generic Yosys synthesis with zero reported structural problems.

The pure Python semantic model enumerates all 256 complementary payload pairs
at exact period 434. The public RTL oracle puts every byte in both payload
slots at legal period two, then runs retained exact-period pairs `00/ff`,
`55/aa`, `aa/55`, and `ff/00`. It checks TX value and direction after every
accepted edge, both payload/program readbacks, exact HALT at PC7, and RX result
capture on the eighth bit before another clock edge. Direct-engine traces also
cover both bit orders, nonzero RX, three bursts with slot reuse, arbitrary
instruction changes during a burst, and payload changes after capture.
Separate adversarial traces cover period zero/one, reserved fields,
a manual-period violation, disable freeze, and reset during a burst.

Formal properties quantify over arbitrary instruction, payload, sampled input,
enable and legal period values. They prove bit-step countdown, GPIO value and
direction updates, eighth-step completion, final hold, PC/LOOP advance,
payload-slot toggle/reuse, reset and disabled-edge behavior. Covers reach
period two, the first completed burst, and a second burst using slot one.

Generic synthesis reports 2,783 abstract cells and 410 state bits. The merged
K-SHIFT-8 baseline was 2,534 cells and 385 state bits, so this screening delta
is +249 cells and +25 state bits. The state delta decomposes exactly into the
alternate payload byte (8), latched period (16), and payload selector (1).
An initial local synthesis screen used 412 state bits: two redundant retained
mode flags were then removed, deriving both from a nonzero period. The final
screen saves two state bits but does not reduce the total generic cell count.
These generic counts are not CMOS5L area,
timing, utilization or fit evidence.

## Falsification and boundary

The first formal run failed temporal induction at a checker assertion because
the checker had not yet stated the reachable-state invariant that a timed wait
implies a valid latched burst and period. Simulation was green; the generated
induction trace represented an unreachable arbitrary state. The invariant was
added explicitly, after which the proof and covers passed. The failed run is
reported here and is not relabelled as a design pass.

The [official Jane Street competition page](https://blog.janestreet.com/protocol-emulator-asic-competition/)
was rechecked on 2026-10-05. It still requires an open-source general-purpose
reprogrammable protocol emulator, names UART/SPI/I2C as starting protocols,
sets the CMOS5L target and current maximum to 6x4 tiles, and gives the deadline
as 2027-01-18. This candidate satisfies only the frozen digital UART-TX
waveform at the RTL/formal rung. UART receive, baud tolerance, pad behavior,
CMOS5L area/timing, gate-level behavior, FPGA and silicon are NOT_EVALUATED.
