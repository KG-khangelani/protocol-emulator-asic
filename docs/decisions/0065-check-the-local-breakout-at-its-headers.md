# D65 — Exercise the retained images at the Lattice breakout headers

25 November 2026. Board 4 provides digital samples. A local fixture would allow a probe at the receiver and a DS18B20 on DQ. The Lattice iCE40UP5K-B-EVN uses the same SG48 device as FabricFox v2. Figures A.3 and A.4 of Lattice guide FPGA-UG-02001-1.2 indicate that every one of the 26 signals used in the retained UART, SPI and open-drain FPGA images reaches J2 or J3. A standard RP2040 Pico exposes 26 GPIOs. Test this before asking for a second FPGA build or an I/O expander. [Lattice guide](https://www.latticesemi.com/view_document?document_id=51987) · [Pico data sheet](https://datasheets.raspberrypi.com/pico/pico-datasheet.pdf) · [Existing FPGA constraints](../../experiments/fpga_uart/tt_fpga_fabricfoxv2.pcf)

Use the previously packed E0051 UART, E0057 SPI and E0059 open-drain configurations. Check every signal through the package, board header and chosen Pico connection. On each decoded image, load and read back the relevant programs using only the pins available to the Pico. Exercise a working transaction and adverse controls. For the sensor test, provide an executable one-device bench with an identity check, the FPGA's 17 slots and raw DQ sampling. For UART and SPI distinguish the FPGA's package driver from the external peer during loader readback and turnoff. Keep the original images, cutoffs and hardware inputs. The bench clock is an external nominal 12.5 MHz on J3.8. The board's separate 12 MHz oscillator connects to J2.16.

Reject compatibility if a signal lands on a rail, configuration net, unisolated switch or inaccessible pad, an image fails real package-level replay, readback data are corrupt, ownership conflicts, or an expected wire response cannot be recovered. Record connector assembly, switch settings, bias, probe placement and outstanding physical checks. Successful replay qualifies the wiring for a bench trial. The local board, calibrated trace and real sensor responses each require their own physical observation.
