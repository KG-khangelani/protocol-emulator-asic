# D66 — Measure the native receiver holding SCL through a read request

25 November 2026. E0058 exercised deadline-adjacent stretches digitally. E0060 established GPIO18/19 as the clean physical I2C1 receiver on FabricFox board 4. Exercise an actual delayed response on that same bus with the E0059 FPGA configuration. Use the 96-word release and 108-word guard unchanged. [I²C acceptance contract](../specs/p-i2c-controller-100k.md) · [Receiver crossover](../../evidence/E0060-i2c-receiver/README.md)

At address 2E the native RP2350B target should receive the requested register 96 and hold its transmitter FIFO empty after the read request. Compare immediate service, a 1 ms wait and an unserviced request, followed by nominal 3.85 and 4.15 ms delays and a fresh immediate read. Measure the actual interval between the FPGA releasing SCL and the receiver sampling it high. The service delay begins at a software event, so the pin trace determines the electrical sequence. Capture SDA18, SCL19, both drive commands and HALT in one PIO snapshot. Keep the same pull-up configuration. [MicroPython target callbacks](https://docs.micropython.org/en/v1.29.0/library/machine.I2CTarget.html) · [RP2 FIFO implementation](https://github.com/micropython/micropython/blob/v1.29.0/ports/rp2/machine_i2c_target.c) · [NXP UM10204 §3.1.9](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)

A completed read must decode both addresses, register, reply 01, ACK ownership, final NACK, STOP and HALT. The delayed read must show SCL staying low with the FPGA driver released. The expired case must show the addressed prefix, no completed reply, both FPGA drive commands released at HALT and the receiver still observing SCL low. Establish the actual wait and allow the sample-grid uncertainty when comparing HALT to the 50,000-clock deadline plus 16 cleanup clocks. At the nominal 12.5 MHz bench clock these are 4 ms and 1.28 µs. Record target request, byte supplied, terminal raw pages, post-target idle and board restoration. Verify every occupied program byte at every cold load. Retain deviations and rerun the matched cases.

Use the public visitor interface on an idle board, with a bounded acquisition and restoration of the stock configuration. These measurements characterize a real receiver's digital response. Selecting the I²C firmware for a known application load still requires calibrated voltage crossings and measurement uncertainty.
