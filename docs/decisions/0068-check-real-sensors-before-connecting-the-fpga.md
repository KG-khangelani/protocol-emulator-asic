# D68 — Use the Pico alone to establish the sensor references

26 November 2026 SAST. The Western Cape sensor basket can be assembled before the local FPGA and calibrated instruments arrive. E0063's Pico program also needs the FPGA for its cold load. Give the sensor-only fixture its own entry point. Keep it usable as an independent reference when the FPGA is subsequently connected. [Local parts](../research/western-cape-bench.md) · [FPGA acquisition](../../evidence/E0063-local-breakout/README.md)

On one physically wired sensor at a time, use the standard Pico MicroPython 1-Wire controller on GP19. Sample at the sensor DQ using a separate GP18 lead. Require exactly one family-28 ROM with valid CRC, a nonconstant scratchpad with valid CRC read using that ROM, an addressed power query, and a separately captured broadcast power query. Decode the reset, presence, `CC B4` and seventeenth slot. Recheck the identity and addressed response after the broadcast. Reject a missing sensor, corrupt record, exchanged power labels or the same ROM supplied twice. Record the wiring and both ROMs. The query starts no temperature conversion. [Device commands and timings](https://www.analog.com/media/en/technical-documentation/data-sheets/ds18b20.pdf) · [MicroPython master](https://github.com/micropython/micropython-lib/blob/master/micropython/drivers/bus/onewire/onewire.py)

Before a sensor is available, exercise the master and acquisition on publicly available hardware with a scripted open-drain responder and a genuinely empty branch. Test both returned bit values, the no-presence control, and an identity or scratchpad fault. Keep the programmed peer's ROMs separate from actual sensor records. Only physical devices with declared VDD connections can qualify the purchased pair. The FPGA's follow-on trial still requires its own capture and readback.

After the first run accepted both programmed identities, add a crossover control. Retain both identities and swap their returned power bits in fresh acquisitions. A peer that releases DQ throughout every power read can look externally powered even with a valid scratchpad. Under a declared parasite connection that silent response must fail. The optional four-capture comparison lets the same two real devices demonstrate both responses once they arrive.
