# D67 — Test the observable MISO level under opposite receiver bias

25 November 2026. E0057 measured the FPGA's MISO enable and one receiver pin at 8 ns intervals. The Welland HAT joins UIO3 / RP2350B GPIO28 to UI3 / GPIO20 through Pi GPIO11. The SPI wrapper already isolates both MCU output drivers during runtime. Test whether the released branch moves to a weakly imposed logic level soon enough to be visible at either input. A successful byte or a falling enable witness alone cannot establish that observation. [E0057 handoffs](../../evidence/E0057-remote-spi/README.md) · [Provider pin map](https://docs.fpgas.online/en/latest/boards/tt-fpga/overview/pin-mapping.html)

Use the retained E0057 board-4 configuration and the 126-word watchdog program. Capture SCK, MOSI, CS, MISO28, linked MISO20, enable, HALT and the project clock together at nominal 125 MS/s. Compare no internal pull, a pull on GPIO28 alone and equal pulls on both inputs, in both bias directions. Record pad configuration and read back output-enable-to-pad for both MCU pins. Keep the external requester and image fixed. Run both A4 and A5 so the first reply bit is respectively low and high. Exercise a held abort, a selected clock stall and 400, 424 and 480 ns abort/reselect gaps. Repeat in reverse order. Use a known bad program write as an acquisition control.

At the release event record when each input first reaches the imposed bias and when it stays there, limiting the observation to the next active driver or capture end. Check the level at reselection, count recrossings and decode the actual fresh reply and timeout. Report same-polarity and no-pull cases separately from opposed trials. An input that never moves or moves after reselection fails that digital observation. A repeatable difference under bias can identify when a receiver observes a changed level. Electrical turnoff still requires a calibrated target-branch current or differential-voltage capture, a measured load and uncertainty. Keep qualified hardware and firmware intact.
