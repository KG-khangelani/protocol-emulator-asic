# D62 — Compare the I²C clock command with two receiver inputs

25 November 2026. E0059 recorded extra SCL transitions on all 18 transfers even though both firmware images read the expected registers. The existing FPGA image already routes the controller's SCL output enable to dedicated output bit 1, RP2350 GPIO34. The board HAT links GPIO19 and the native I2C1 SCL input on GPIO27 through the JA3 and JB3 connections. A wide PIO input can observe both pins, both drive commands, SDA and HALT in one sample. Use the same board, FPGA bitstream, 12.5 MHz core clock, hardware target, program readback and six requests as E0059. [Baseline records](../../evidence/E0059-remote-i2c/README.md) · [FPGA status wiring](../../experiments/remote_i2c/fabricfox.v) · [Provider pin map](https://docs.fpgas.online/en/latest/boards/tt-fpga/overview/pin-mapping.html)

Before examining new traces, predict 76 SCL drive-command transitions for a complete transfer and 20 for first-address NACK, as in E0058. Count each input's raw transitions. For each high or low interval shorter than 500 ns, classify whether the controller held SCL released, asserted it, or changed its command during the interval, including both boundary samples. Report disagreement between GPIO19 and GPIO27 and the delay from each command to the receiver level. Use unfiltered samples for these quantities. A fixed five-sample decode is a diagnostic inherited from E0059. A clean-wire claim requires the raw protocol decoder to pass.

Run the native bias at nominal 10 MHz sampling, the same grid with the extra linked pull-ups, and a separate native-bias run at 8 MHz. Require correct selected-byte and NACK outcomes, complete pin journals, an idle bus and board restoration. If a pin shows extra transitions with a steady command, repeated commands cannot explain those measured excursions. If simultaneous samples disagree, record which input saw the transition. Both inputs share a chip and timebase. Absolute voltage, resistance, calibrated uncertainty and output current still require the instrumented bench.
